# Claude Codeへの依頼：RE:MAKE コンサルティングスキルを使える形にする

## 依頼
添付の「REMAKE_コンサルティングスキル_v1.zip」と「REMAKE_コンサルティング実践スキル_完全版.md」を読み、知識集を、実際の相談・面談・教育に使える一つの形へまとめてください。

まず既存のプロジェクトを確認し、再利用できるものがあれば活用してください。以前検討していたポリア式の目標達成プログラムと重なる場合は、別物を増やす前に統合案を示してください。

具体的な製品形式はまだ最終決定していません。最初の案として、スマートフォンでも使える「コンサルティング伴走Webアプリ」のローカル試作品を想定しています。最初に短い画面構成と実装方針を提示し、大きな判断だけ確認してください。細かな判断は合理的な仮定を明示して進めてください。

## 目的・対象
- RE:MAKEのAI導入支援、個人事業主・企業の業務改善、店舗支援、NLP教育に使う
- 支援者が顧客の話を整理し、課題、選択肢、次の行動を一緒に決められるようにする
- 「情報が多い」ではなく、「誰が・いつまでに・何をするか、どう確かめるか」が明確になることを成果とする
- 顧客向けセルフサービスをいきなり公開せず、まず支援者自身が試せる形にする

## 最初に読むもの
1. ZIPを展開した remake-consulting-skill/SKILL.md
2. references/workflow.md：ポリア式の進行
3. references/playbook.md：実務技法

6. references/corrections.md：誤読・一般化の修正
7. references/sources.md と video-map.md：出典と確認範囲

完全版Markdownは全体把握・検索用です。元108資料の全文・35動画の全編を検証した資料ではありません。ユーザー提供の要約と、重要原則の一次資料監査を統合したものです。未確認の内容を確認済みに変えないでください。

## MVPの画面案
| 画面 | できること |
|---|---|
| 相談の開始 | 目的、現状、期限、制約、望む成果を入力 |
| 問題の整理 | 事実・解釈・仮説・未確認事項を分けて編集 |
| 計画の比較 | 複数案、費用、負担、期待効果、リスクを比較 |
| 行動計画 | 担当、期限、完了条件、測定方法を整理 |
| 振り返り | 実績と仮説を比べ、次の一手を決める |
| 出力 | 面談メモ、提案の骨子、行動計画をMarkdownで保存 |

この画面案は出発点です。既存実装に合う、より簡潔な構成があれば理由を示して採用してください。

## UXの要件
- スマートフォンで読みやすく、長文を一度に表示しない
- 1画面1目的。最初の質問は1〜3問程度に分ける
- 既に入力した情報を何度も聞かない
- 表、段階表示、カードなどで現在地と次の操作が分かる
- 入力は後から訂正でき、戻る操作で消えない
- 事実・仮説・目標・実績の違いが見た目でも分かる
- 担当や期限が未合意なら「案」「未定」と表示する
- 最後は必ず「今日できる最小の一手」を表示する

## 実装方針
1. 現在の作業フォルダ、既存アプリ、依存関係、起動方法を確認する
2. 既存資産を再利用する範囲と変更範囲を短く示す
3. まず架空の相談データで主要な一連の操作を実装する
4. AI接続がなくても画面・編集・出力を試せる構成にする
5. AI接続がある場合は、既存の安全な接続方法と利用条件を確認する
6. テストと修正を行い、起動方法、完成した機能、未実装部分を報告する

有料サブスクリプションを持っていることと、API利用権・料金は別です。APIが使える、無料で使えると決めつけないでください。未接続時のデモ出力は「サンプル」と明記し、実際のAI回答と混同させないでください。

## 内容上の重要ルール
- 顧客便益÷料金と、料金÷提供原価を区別する。一律20万円以上などの基準を強制しない
- 売上＝客数×平均客単価。期間、税、値引き、分母をそろえる
- 未取得データをゼロにしない。観測できた期間と全期間を区別する
- 導入前後の変化だけで原因や効果を断定しない
- 自由回答で探索し、仮説を確認質問で検証する。誘導質問だけにしない
- AIが作った文章・数値・引用は自動的に正しいものと扱わない
- 作業時間の偽装、不要な納品遅延、顧客への不安の煽りを組み込まない
- NLPは対話・学習の補助。治療・成果・人格変容を保証しない
- 法律、税務、医療などは確認事項を整理し、必要な専門家確認につなぐ

## データ・権限
- 試作品では実在の顧客情報を投入せず、架空データを使う
- APIキー、Cookie、認証セッション、個人情報をログや画面に出さない
- 保存方式と削除方法を明示する。ブラウザ保存だけで安全性を保証しない
- 外部AIへの送信、クラウド保存、本番公開、課金、既存データ削除、認証・権限変更は、この引き継ぎ文だけで承認済みと扱わず、必要な確認を取る
- 既存ファイルを無断で置き換えない。変更は追跡・復元できる形で行う

## 完成条件
- 架空の相談を入力し、問題整理→計画比較→行動計画→振り返りまで操作できる
- PCとスマートフォン幅でレイアウトと操作を確認できる
- 入力の訂正が結果へ反映される
- 面談メモと行動計画をMarkdownで出力できる
- 不足情報、未合意、デモ表示が明示される
- 価格の倍率、欠測、因果関係のテストが通る
- 起動方法と確認可能なURLを提示する。ローカルURLはスマートフォンから開けるURLと同一ではないので、実際に確認した範囲を報告する

## 最初の返答で欲しいもの
1. 読み取った目的を3行以内
2. 既存資産を確認した結果
3. 最小構成の画面案と、最初に作る範囲
4. 作業を進めるために本当に必要な質問だけ

構想の説明だけで終わらず、確認が不要な範囲は試作品の実装・テストまで進めてください。出来たことと出来ていないことは正直に分けて報告してください。
