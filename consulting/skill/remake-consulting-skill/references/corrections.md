# コンサルティングスキル作成前の品質監査

2026-10-17。対象はユーザー提供の108件参照リストとNotebookLMの35動画要約。35動画を視聴・字幕照合したものではない。以下は要約の内部矛盾、一般化しすぎた表現、スキル運用上の修正点。動画本人の発言ミスと断定しない。

## 必須修正

| 箇所 | 問題 | スキルに採用する置換ルール |
|---|---|---|
| 総括4の3x10x | 個別説明2では顧客価値が価格の3〜10倍だが、総括は価格が顧客価値の3〜10倍へ逆転 | 価格P、期待便益V、提供原価Cを分離する。顧客側の便益倍率はV/P。3〜10倍は特定提唱者の目安であり万能条件でも成果保証でもない。原価側のP/Cと混同しない |
| 最低20万円／常に高単価 | 全業態・全案件への一般化は不適切 | 顧客課題、予算、便益、提供範囲、リスク、原価、代替案から価格案を作る。入口診断や小実験も認める。売上増をそのまま顧客利益にしない |
| 納品を1〜2週間わざと遅らせる | 価値を偽装するための遅延は信頼と顧客便益を損ねる | 合意した検証・品質確認・導入準備に時間を使い、可能なら早期成果を共有。納期は顧客都合と品質基準で決める。作業時間を偽らない |
| オープン質問を避けクローズド徹底 | 発見段階で誘導・確証バイアスを強める | 発見は中立的なオープン質問→具体例・根拠・例外→仮説提示→クローズド確認。『期限はいつ、何に使いますか』は必要な探索質問。相手が否定できる余地を残す |
| AIで思い込み排除 | AIにも誤情報、偏り、架空根拠がある | AIは候補生成・構造化・反証補助。数値と引用は正本で確認。反対仮説、例外、欠損を併記し、判断責任者を定める |
| 売上＝新規客増＋リピート客増＋一品単価アップ＋注文数増 | 人数、円、数量を加算する次元不整合 | 4項目は改善レバーとして記述。恒等式は売上＝来店客数×平均客単価。またはΣ(商品別販売数量×実売単価)。税・値引・返金の基準と期間を統一。客単価＝1人当たり注文点数×販売点数加重平均単価とするなら対象商品と客数分母を定義 |
| MECE＝相手が納得する要素 | 納得だけでは漏れ・重複のない分類にならない | 対象範囲、分類軸、集計単位を先に決める。重複0・未分類の有無を点検。相手の納得は別の伝達品質条件 |
| ボトルネック1つだけ/KPI1行 | 優先テーマを絞ることと監視指標を1つにすることを混同 | 最優先改善指標は絞るが品質・顧客満足・負荷・安全の悪化を検知する補助指標を残す。定義、分母、頻度、責任者、閾値、次の行動を記録 |
| コンサル効果・AI効率倍率 | 事例や自己申告を普遍的効果と誤認しやすい | 対象・条件・比較群・期間・サンプルを伴わない倍率は参考値。導入前後のみでは季節性や他施策の影響を分離できない。実測・推定・目標・保証を別欄にする |
| カウンセリング＝マイナスからゼロ | 役割理解の比喩であり専門職の包括的定義ではない | 医療的診断・治療と混同しない。コーチング、助言、相談支援の役割を合意し、専門家紹介の条件を設ける |
| 理論・NLPを提示して説得 | 名前のある理論を挙げても主張の真実性は増えない | 根拠の強さと適用範囲を説明し、権威づけのために理論名を付けない。心理類型で人格・意図を断定しない |
| 質問多め／完璧な事前準備 | 面談コスト増、着手の先延ばしにつながる | 既知の情報は再質問せず、意思決定を変える質問を優先。初回3問等で段階化し、不確実な前提は仮置き・検証期限を明示 |

## 採用を補強できる一次資料

1. 中小機構『経営力再構築伴走支援』：一方向の助言ではなく、対話・傾聴を通じた課題への気づき、自己変革・自走化が中心。
https://bansoushien.smrj.go.jp/about/
公式ガイドライン公表ページ：https://www.smrj.go.jp/news/2023/ool3bn000000cl9g.html
PDF：https://www.smrj.go.jp/news/2023/ool3bn000000cl9g-att/guideline.pdf

2. GOV.UK『Using in-depth interviews』：中立的なオープン質問、具体的な出来事、追質問、面談設計と同意確認を推奨。クローズド質問一辺倒にしない根拠。
https://www.gov.uk/service-manual/user-research/using-in-depth-interviews

3. Jonathan Stark本人『Best of: Pricing Professional Services』：価値ベース価格は顧客にとっての価値を起点にするもの。これは提唱者の実務的主張であり、あらゆる案件の唯一解ではない。
https://jonathanstark.com/dl/best-of-pricing-professional-services.pdf
本人サイトは早く成果を届ける価値も強調：https://jonathanstark.com/

4. NIST AI 600-1『Generative AI Profile』：生成AIは誤った内容を確信的に示し、架空の論理・引用で誤信を増幅する場合がある。AI出力を無偏見な正本として扱わない。
https://nvlpubs.nist.gov/nistpubs/ai/NIST.AI.600-1.pdf

5. HBS AI Institute『Navigating the Jagged Technological Frontier』：BCGの758人を対象にした特定実験。AIが適するタスクでは改善、能力境界は一様ではない。2023年GPT-4の特定条件から、今の全AI・全業務に一律効果を保証しない。
https://aiinstitute.hbs.edu/navigating-the-jagged-technological-frontier/
