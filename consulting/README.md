# RE:MAKE コンサル道場

RE:MAKE のAI導入支援・業務改善・店舗支援・NLP教育のための、**学ぶ → 確かめる → 実際の相談に使う** を一つにした試作品。
成果は「情報が多いこと」ではなく、**誰が・いつまでに・何をするか、どう確かめるか** が決まること。

- 依頼書：[`skill/HANDOFF.md`](skill/HANDOFF.md)
- 元資料：[`skill/remake-consulting-skill/`](skill/remake-consulting-skill/)（ユーザー提供のスキルパッケージ v1）

## 起動

```bash
npm run consult:build     # dist/index.html（単一HTML）と dist/artifact.html を作る
open consulting/dist/index.html   # そのまま開ける（サーバー不要）
npm run consult:serve     # http://localhost:8787/ と同じWi-Fi用のURLを表示
```

スマホで試す場合は、`consult:serve` が表示する LAN の URL を同じWi-Fiの端末で開く。
`localhost` の URL はスマホからは開けない。

## 画面（5タブ）

| タブ | できること |
|---|---|
| ホーム | 今日の1枚、進捗、コース、今日できる最小の一手 |
| 学ぶ | 知識333（13章×4段階）。章・コース・レベル・キーワードで絞る。各項目に要点・使い方・落とし穴・架空例・出典 |
| 練習 | 333問のクイズ（範囲・問題数を選ぶ、まちがえた問題の再挑戦）、誤り探しドリル16問、計算ツール3種 |
| 伴走 | 相談の開始 → 問題の整理 → 計画の比較 → 行動計画 → 振り返り → 出力（Markdown） |
| 資料 | ツールの説明、重要ルール、出典台帳108件、RE:MAKEスキル資料の閲覧、データの保存と削除 |

依頼書のMVP案（6画面）は「伴走」タブの6ステップとして実装した。学習機能を加えたため、ナビゲーションは5タブにまとめた。

### 伴走の決まりごと

- 1画面1目的。開始は3問だけで、詳しい項目は折りたたむ
- 事実（青）・解釈（灰）・仮説（付箋の黄）・条件（紫）・未確認（赤の破線）・目標（緑）・実績（青緑）を色と形で分ける
- 担当・期限は、空なら **未定**（赤）、相手と未合意なら **〜（案）**（黄）と表示し、出力にもそのまま出る
- 不足・未合意は常に件数を表示し、該当ステップへ飛べる
- どのステップの下にも **今日できる最小の一手** を表示する（未記入なら「提案（未合意）」として出す）
- 入力は自動保存。戻る・ステップ移動・再読み込みで消えない
- 架空のサンプル相談には「サンプル」と明記する。AIには接続していない

## 知識333の根拠区分

| 区分 | 意味 |
|---|---|
| RE:MAKE資料ベース | ユーザー提供の108資料の要約・35動画の要約・一次資料監査を統合したスキルに基づく。元資料の全文・動画全編は未確認 |
| 一般知識・原典未照合 | 一般的なコンサルティング知識としてClaudeが作成。参考書籍は手がかりで、該当箇所や引用は確認していない |

未確認の内容を確認済みとして表示しない。架空例の数値は説明用で、実績・相場・効果ではない。

## テスト

```bash
npm run consult:test       # 価格倍率・欠測・因果・相談モデル・内容の検証
npm run consult:validate   # 知識カードの形式・禁止表現チェック
```

テストで確かめていること：V/P と P/C を取り違えない／年額と月額を換算してから比べる／欠測を0にしない（観測日の平均と全期間を区別）／分母0の増減率は計算不可／比較群のない前後比較で因果を断定しない／未合意は「案」、空は「未定」／訂正が出力に反映される／サンプル表記と最小の一手が出力に入る。

## データと保存

- 進捗と相談は、そのブラウザの `localStorage`（キー `remake-dojo:v1`）にだけ保存する。サーバーにもAIにも送らない
- 削除は「資料 › データと保存 › このブラウザのデータを削除」、または相談一覧の「削除」
- ブラウザ保存は安全性を保証しない。試作品には実在の顧客情報を入れない
